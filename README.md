# Тестовое задание
Написать телеграмм-бота на Python, который интегрируется с сервисом ChatGPT для генерации текста по запросу пользователя. 
 Требования: 
1. Бот должен отвечать на /start и /help команды.
2. При отправке любого текстового сообщения бот должен обращаться к API сервиса ChatGPT и генерировать ответ на основе этого запроса. 
3. Бот должен сохранять историю диалогов и использовать контекст предыдущих сообщения для формирования более качественных ответов.
4. Контекст диалога должен сбрасываться при вводе команды start, а также по нажатию кнопки Новый запрос.

# Решение
Реализован и развёрнут бот в Telegram. Доступен по ссылке: https://t.me/dialog_context_bot

## Локальная установка и запуск

Клонируем репозиторий:
```
git clone git@github.com:alexfofanov/dialog-context-bot.git
```
Переходим в папку проекта:
```
cd dialog-context-bot
```
Создаём и при необходимости редактируем файл настройки проекта .env
```
cp .env.sample .env
```
Запуск сервиса: 
```
docker compose up --build -d
```
Остановка сервиса: 
```
docker compose down -v
```
